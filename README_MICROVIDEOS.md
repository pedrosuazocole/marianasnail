# Mariana Nails v1.7.0 — Biblioteca audiovisual propia

36 videos MP4 distintos, tres por módulo, cada uno relacionado con una lección. Formato: microlecciones visuales originales, sin audio, de ~24 s con explicación conceptual, criterio técnico y ejercicio. **No son demostraciones manuales de procedimientos**; no publicitar como 36 tutoriales prácticos completos. Para formación comercial de técnicas se requieren videos demostrativos grabados o autorizados, evaluación y supervisión adecuada.

Archivos en public/videos; no dependen de YouTube. Mantener el volumen SQLite de Railway. El despliegue no modifica los datos existentes.
